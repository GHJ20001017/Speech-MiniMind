# 00. 语音基础

这一章只使用 Python、NumPy 和 Matplotlib，不引入 PyTorch。目标是先建立对语音信号的直觉：语音不是“文字的另一种输入格式”，而是一段随时间变化的连续波形。

## 1. WAV 文件里有什么

最重要的三个量是：

- **采样率（sample rate）**：每秒记录多少个采样点，例如 16 kHz 表示每秒 16000 个点。
- **位深（bit depth）**：每个采样点的数值精度，常见的是 16-bit PCM。
- **通道数（channels）**：单声道为 1，立体声为 2。

采样率决定可表示的最高频率。根据 Nyquist 采样定理，16 kHz 音频理论上最多表示 8 kHz 以下的频率，这已经覆盖了大部分语音识别需要的信息。

## 2. 波形、振幅和能量

把采样点按时间排列，就是波形。振幅反映瞬时声压的相对变化，但它不等于响度。一个常用的短时能量指标是均方根（RMS）：

```text
RMS = sqrt(mean(x^2))
```

RMS 可以帮助我们观察静音段、语音段和录音音量是否稳定。脚本中的 RMS 是对整段音频计算的全局值；训练模型时通常会在 20～30 ms 的窗口上计算短时 RMS。

## 3. 过零率

过零率（zero-crossing rate, ZCR）表示波形穿过 0 的频率：

```text
ZCR = number of sign changes / number of samples
```

清音、噪声通常有较高的过零率，浊音通常较低。ZCR 不是强大的语音特征，但它非常适合作为理解时域信号的第一个例子。

## 4. 频谱和 Mel 频谱

波形告诉我们“声音随时间怎么变化”，短时傅里叶变换（STFT）告诉我们“每个时间片包含哪些频率”。语音模型常用如下流程：

```text
波形 → 分帧/加窗 → STFT → 功率谱 → Mel 滤波器组 → log-Mel 频谱
```

Mel 频率尺度更接近人耳对频率的感知。后续的声学 encoder 通常以 log-Mel 频谱作为输入，而不是直接读取原始波形。

## 5. 运行实验

准备一个 WAV 文件后运行：

```bash
python scripts/analyze_audio.py example.wav --plot outputs/example.png
```

观察三个问题：

1. 说话段和静音段在波形上有什么区别？
2. 提高或降低录音音量后，RMS 和波形会怎么变化？
3. 同一个人的元音和辅音在频谱上有什么差异？
